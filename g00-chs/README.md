# g00-chs

替换用的中文贴图（984 个 `.g00` 文件，共约 16 MB）。

## 用途

这些是 RealLive 引擎的图片封装文件，覆盖界面按钮、章节标签、道具与技能名称、打字小游戏提示等需要显示文字的图。游戏文本由 `version.dll` 在内存中替换，但**画在图片里的字**改不了，只能替换贴图文件。

## 安装

把本目录下所有 `.g00` 文件复制到游戏安装目录的 `g00/` 文件夹，覆盖同名文件即可。

```text
<Steam 库路径>/steamapps/common/Tomoyo After ~It's a Wonderful Life~ English Edition/g00/
```

覆盖前建议先备份原来的 `g00/` 目录。

## 注意

- 本目录只包含需要替换的贴图，不是完整的 `g00/`（游戏本体共有 2000 多个文件）。**只覆盖同名文件，不要删除其余文件**。
- 贴图与 `patch/` 里的文本是两套独立的东西：只装 `version.dll` 不换贴图，画面里的字还是原文；只换贴图不装 DLL，文本仍是原文。
